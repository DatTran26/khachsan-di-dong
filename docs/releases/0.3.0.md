
# Release 0.3.0

Ngày: 2026-11-02
Tag: `v0.3.0`
Mốc so sánh: commit `082f810` (mốc 0.2.0) đến `3b4fd26` (HEAD của worktree release).

App hiện khai báo `0.3.0+3`; server khai báo `0.3.0`. Nội dung dưới đây là tổng hợp từ mã nguồn, test và workflow trong repository; chưa phải bằng chứng deploy hay UAT.

## Trong bản này

- **App Flutter:** dashboard có thao tác nhanh/check-in, tìm phòng và ô phòng PMS trực quan; màn đăng nhập có slideshow ảnh; các màn dùng loading skeleton, trạng thái offline/reconnect và design token dùng chung. Bổ sung kiểm thử layout, responsive, accessibility và realtime state.
- **Phiên và realtime:** REST/Socket.IO dùng `API_URL`; xử lý handshake hết hạn, tài khoản bị khóa, đăng xuất lặp và đổi tài khoản để không giữ state hoặc request của phiên cũ.
- **Backend:** lượt tạo tóm tắt AI có request ID và giới hạn chi phí mỗi lượt; dashboard không tính việc đang chờ xác nhận là quá hạn; fixture và test housekeeping/dashboard được bổ sung.
- **CI:** workflow app chạy `flutter analyze`, test và build Web trên push/PR; khi PR xếp chồng đổi nhánh đích, workflow được chạy lại. Workflow backend hiện có tiếp tục giữ typecheck, lint, test, migration/seed, benchmark realtime và build.
