# Release 0.2.0

Ngày: 2026-10-14  
Tag dự kiến: `v0.2.0`  
Nguồn: `develop` tại `082f810` (merge `develop-dat` vào `develop`), cộng ghi chú release này.

App `0.2.0+2`. Server `0.2.0`. Số build Flutter tăng từ `+1` để `versionCode` không đi lùi.

## Trong bản này

- Tóm tắt vận hành: API AI có báo cáo dự phòng, màn quản lý, mức dùng ngân sách, và hình dạng dữ liệu được đánh phiên bản.
- Dashboard: việc quá hạn theo phòng, cờ và số lượng theo spec, thẻ thống kê lọc lưới phòng.
- Buồng phòng: ảnh nghiệm thu cho nhân viên và quản lý; phiếu việc bám theo việc.
- Danh mục: quản lý thêm, đổi tên và tắt loại phòng. Ô phòng ngừng phục vụ chỉ hiện "Ngừng phục vụ".
- Cảnh báo quá hạn mở đúng phòng, danh sách việc hoặc nhật ký kiểm toán.
- Nền: health check trả 503 khi cơ sở dữ liệu không lên, Biome trong CI, seed demo và ca cao điểm, ma trận RBAC.
- Mã nguồn có ghi chú dartdoc/TSDoc cho app và server.

## Cách lấy bản này

```powershell
git fetch origin tag v0.2.0
git checkout v0.2.0
.\setup.cmd
.\dev.cmd
```

Tag và GitHub Release chỉ có sau bước xuất bản. Nếu tag chưa có, lấy đúng commit trên `main` sau merge `release/0.2.0`.
