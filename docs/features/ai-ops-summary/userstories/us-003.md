# US-003: Điều phối từ mục việc cần chú ý

## User Story

As a **quản lý**, I want **bấm việc cần chú ý để tới dashboard**, so that **tôi điều phối ngay việc quá hạn / phòng ngừng phục vụ**.

| ID | Priority |
|----|----------|
| FR-ai-ops-summary-012 | Should |

## Acceptance Criteria

### AC-001 — Liên kết dashboard

```gherkin
Given bản tóm tắt hoặc báo cáo mẫu đang hiển thị mục việc cần chú ý
When tôi bấm một mục (việc quá hạn hoặc phòng ngừng phục vụ)
Then hệ thống đưa tôi tới vị trí tương ứng trên dashboard
```
