# US-007: Ghi nhật ký và lan truyền realtime

<!-- built from draft SRS, may need refinement -->

## User Story

As a **hệ thống**, I want **ghi nhật ký mọi thay đổi và phát realtime**, so that **mọi thiết bị thấy cùng một nguồn sự thật và có truy vết**.

## Linked Requirements

| FR | Priority | Notes |
|----|----------|-------|
| FR-maintenance-011 | P0 | Nhật ký ai/khi/từ→sang + phát realtime |

## Acceptance Criteria

### AC-001 — Mọi đổi trạng thái có nhật ký

* **Type:** business-rule
* **Covers:** FR-maintenance-011, CAP-maintenance-06

```gherkin
Given một thao tác đổi trạng thái việc hoặc phòng bảo trì thành công
When hệ thống hoàn tất ghi
Then có bản ghi nhật ký gồm ai, khi nào, từ→sang
```

### AC-002 — Cập nhật lan tới thiết bị khác

* **Type:** happy-path
* **Covers:** FR-maintenance-011, CAP-maintenance-05

```gherkin
Given thiết bị khác đang mở danh sách/chi tiết liên quan
When máy chủ lưu thay đổi bảo trì thành công
Then thiết bị khác nhận và hiển thị trạng thái mới (mục tiêu ≤3 giây theo NFR)
```
