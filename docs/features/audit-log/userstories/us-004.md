# US-004: Loc nhat ky theo thoi gian va nguoi

## User Story

As a **quan ly**, I want **loc nhat ky theo khoang thoi gian va vai tro/nguoi (gom he thong)**, so that **toi thu hep vet khi ra soat**.

## Linked Requirements

| ID | Priority | Notes |

| CAP-audit-log-05 | P0 | |

## Acceptance Criteria

### AC-001 — Loc ket hop

```gherkin
Given quan ly dang xem nhat ky
When dat loc tu-den va chon nguoi/vai tro (hoac "he thong")
Then ket qua la phan giao cac dieu kien, moi nhat truoc
```

### AC-002 — Khoang thoi gian khong hop le

```gherkin
Given moc "tu" sau moc "den"
When ap dung loc
Then hien E-audit-log-002
And khong tra danh sach theo loc sai
```

### AC-003 — Loc rong

```gherkin
Given khong co ban ghi thoa loc
When ap dung loc
Then hien E-audit-log-004 trang thai rong
```
