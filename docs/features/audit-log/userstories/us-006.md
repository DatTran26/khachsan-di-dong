# US-006: Xem nhat ky chung toan he thong

## User Story

As a **quan ly**, I want **xem nhat ky chung gom su kien khong gan phong va loc mo rong**, so that **toi ra soat auth va toan he thong**.

## Linked Requirements

| ID | Priority | Notes |
|----|----------|-------|
| FR-audit-log-010 | Should | P1 |
| CAP-audit-log-06 | P1 | Mo rong man xem cua auth-roles |

## Acceptance Criteria

### AC-001 — Hien thi toan he thong

```gherkin
Given quan ly da dang nhap
When mo nhat ky chung
Then thay ban ghi gom su kien khong gan phong (vd auth)
And co the loc them loai hanh dong, truc, loai doi tuong
```

### AC-002 — Phan quyen

```gherkin
Given vai tro khong phai quan ly
When truy cap nhat ky chung
Then bi tu choi E-audit-log-001
```
