# US-002: Nhận cập nhật realtime và cờ quá hạn

## User Story

As a **người đang xem dashboard**, I want **ô phòng và chỉ số cập nhật trong vài giây kèm cờ quá hạn**, so that **tôi phản ứng đúng việc chậm**.

## Acceptance Criteria

### AC-001 — Realtime ≤3 giây

```gherkin
Given dashboard đang mở và kết nối
When feature nguồn lưu thành công một thay đổi trạng thái
Then dashboard phản ánh thay đổi trong ≤3 giây kể từ lúc máy chủ lưu
And giữ ngữ cảnh bộ lọc đang dùng
```

### AC-002 — Cờ quá hạn

```gherkin
Given việc đang mở có cờ quá hạn từ feature nguồn
When sự kiện tới dashboard
Then ô phòng liên quan được tô cờ và chỉ số "việc quá hạn" tăng
And khi việc hoàn tất cờ biến mất trên dashboard
```
