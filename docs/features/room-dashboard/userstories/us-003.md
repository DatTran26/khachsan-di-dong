# US-003: Lọc phòng theo tầng và nhóm trạng thái

## User Story

As a **quản lý hoặc lễ tân**, I want **lọc lưới theo tầng và nhóm trạng thái**, so that **tôi khoanh đúng vùng cần xử lý**.

## Linked Requirements

| ID | Priority |
|----|----------|
| FR-room-dashboard-007 | Must |

## Acceptance Criteria

### AC-001 — Lọc có kết quả

```gherkin
Given dashboard đang hiển thị đầy đủ phòng
When tôi chọn tầng và/hoặc nhóm đang ở / sẵn sàng / cần dọn / ngừng phục vụ / quá hạn
Then lưới chỉ còn phòng khớp bộ lọc
```

### AC-002 — Lọc rỗng

```gherkin
Given bộ lọc không khớp phòng nào
When kết quả trả về
Then hiển thị "Không có phòng nào khớp bộ lọc."
```
