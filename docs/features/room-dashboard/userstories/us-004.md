# US-004: Báo mất kết nối và tải lại khi reconnect

## User Story

As a **người xem dashboard**, I want **biết khi dữ liệu có thể lỗi thời và tự lấy bản mới khi có mạng**, so that **tôi không ra quyết định trên số liệu cũ**.

## Linked Requirements

| ID | Priority |
|----|----------|
| FR-room-dashboard-009 | Must |

## Acceptance Criteria

### AC-001 — Offline

```gherkin
Given tôi đang xem dashboard
When mất kết nối realtime
Then hiển thị banner "Mất kết nối — dữ liệu có thể chưa mới nhất. Đang thử kết nối lại…"
And dữ liệu được đánh dấu có thể lỗi thời
```

### AC-002 — Reconnect

```gherkin
Given dashboard đang ở trạng thái mất kết nối
When có mạng trở lại
Then hệ thống tải trạng thái mới nhất thay vì ghép dữ liệu cũ
And hiển thị "Đã kết nối lại — dữ liệu đã cập nhật."
```
