# US-003: Báo hoàn tất việc dọn

## User Story

As a **nhân viên buồng phòng**, I want **báo hoàn tất sau khi dọn xong**, so that **quản lý biết phòng chờ kiểm tra**.

## Linked Requirements

| ID | Priority | Notes |
|----|----------|-------|
| FR-housekeeping-005 | Must | chờ xác nhận / chờ kiểm tra + thông báo QL |

## Acceptance Criteria

### AC-001 — Báo hoàn tất

* **Type:** happy-path
* **Covers:** FR-housekeeping-005

```gherkin
Given việc đang ở "đang làm" và gắn với tôi
When tôi bấm báo hoàn tất
Then việc chuyển "chờ xác nhận"
And trục vệ sinh chuyển "chờ kiểm tra"
And quản lý nhận thông báo / thấy việc trong hàng chờ xác nhận
```

### AC-002 — Sai trạng thái

* **Type:** error-path
* **Error code:** E-housekeeping-004

```gherkin
Given việc không còn ở "đang làm"
When tôi bấm báo hoàn tất
Then hệ thống báo "Thao tác không hợp lệ ở trạng thái hiện tại. Tải lại để xem trạng thái mới nhất."
```
